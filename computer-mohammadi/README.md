# فروشگاه کامپیوتر محمدی

فروشگاه مستقل لوازم جانبی موبایل و کامپیوتر.

## فایل‌ها
- `index.html`: فروشگاه مشتریان؛ فهرست دسته‌ها و محصولات فعال را از Supabase می‌خواند و فرم ثبت درخواست سفارش دارد.
- `admin.html`: پنل ورود مدیر، افزودن/ویرایش/حذف محصولات، مدیریت موجودی، وضعیت سفارش، روش ارسال، هزینه ارسال و کد رهگیری.

## زیرساخت
- پروژه Supabase مستقل: `computer-mohammadi`
- شناسه پروژه: `fgfeiilkzoajguabzuex`
- جداول اختصاصی: categories, products, customers, orders, order_items, inventory_movements, store_settings
- RLS روی همه جدول‌ها فعال است.
- فقط دسته‌بندی‌ها و محصولات فعال برای بازدیدکننده عمومی قابل خواندن هستند.
- اطلاعات مشتری و سفارش برای عموم بسته است.
- دسترسی مدیریتی دیتابیس به ایمیل مدیر `raminmkaleybar1363@gmail.com` محدود شده است.
- حساب مدیر در Supabase Auth ساخته شده و ایمیل آن تأیید شده است.

## راه‌اندازی
1. سایت و پنل را از شاخه `computer-mohammadi-store` منتشر کنید.
2. در `admin.html` با ایمیل مدیر و رمز عبوری که فقط خود مدیر تعیین کرده وارد شوید.
3. دسته‌بندی و کالاهای واقعی را با قیمت و موجودی صحیح ثبت کنید.
4. فروشگاه عمومی فقط کالاهای فعال را نشان می‌دهد.

## اتصال ربات روبیکا
- فروشگاه می‌تواند از همان ربات موجود `@RaminJavaherBot` استفاده کند؛ ساخت ربات تازه لازم نیست.
- اتصال این فروشگاه فقط برای ارسال اعلان سفارش جدید و تغییر وضعیت/اطلاعات ارسال به گفت‌وگوی مدیر است.
- وب‌هوک و منطق فعلی ربات رام آنلاین تغییر داده نمی‌شود؛ ربات همچنان به پروژه رام آنلاین متصل می‌ماند. فروشگاه کامپیوتر از API ارسال پیام روبیکا به‌صورت خروجی استفاده می‌کند.
- دو Secret لازم برای اعلان‌ها در پروژه مستقل `computer-mohammadi` ثبت شده‌اند و ارسال پیام آزمایشی به گفت‌وگوی مدیر با موفقیت تأیید شده است. مقادیر را فقط در Supabase نگه دارید و در GitHub یا کد سایت قرار ندهید:
  - `RUBIKA_BOT_TOKEN`: توکن همان ربات `@RaminJavaherBot`؛ توکن را در GitHub یا کد سایت قرار ندهید.
  - `RUBIKA_ADMIN_CHAT_ID`: شناسه گفت‌وگوی مدیر با همان ربات؛ مدیر باید قبلاً ربات را Start کرده باشد.
- مقدار توکن از پروژه قبلی به‌صورت خودکار قابل انتقال/خواندن نیست و نباید از داخل کد یا چت افشا شود؛ آن را فقط در Secrets پروژه جدید وارد کنید.
- تابع آزمایشی پس از تأیید دریافت پیام حذف شده است. دو تابع اصلی اعلان سفارش و تغییر وضعیت ارسال فعال هستند؛ آزمون سفارش واقعی هنوز انجام نشده، چون هنوز محصول و سفارش واقعی در دیتابیس وجود ندارد.
- اعلان‌ها فقط برای مدیر هستند؛ این اتصال به معنی اتصال حساب مشتریان یا دریافت رسید پرداخت فروشگاه کامپیوتر در ربات رام آنلاین نیست.
- مرجع API روبیکا: https://rubika.ir/botapi

## وضعیت فعلی
- قالب واکنش‌گرای فارسی فروشگاه آماده است.
- اتصال نمایش دسته‌بندی و محصولات فعال به دیتابیس انجام شده است.
- پنل مدیریت محصولات و موجودی آماده است.
- بخش مدیریت سفارش‌ها در پنل مدیر اضافه شده و سفارش‌های ثبت‌شده را نمایش می‌دهد؛ مدیر می‌تواند وضعیت آن‌ها را تغییر دهد.
- ثبت درخواست سفارش از طریق Edge Function اختصاصی فعال است؛ کلید مدیریتی فقط در محیط سرور می‌ماند، قیمت‌ها از دیتابیس محاسبه می‌شوند، موجودی بررسی و رزرو می‌شود و سفارش با وضعیت «در انتظار تأیید» ذخیره می‌شود.
- لغو سفارش باعث بازگشت خودکار موجودی رزروشده می‌شود؛ ثبت سفارش برای هر شماره تلفن محدودیت زمانی ساده دارد.
- ایندکس‌های کلید خارجی جاافتاده اضافه و سیاست‌های RLS مدیر بهینه شدند؛ دسترسی عمومی کاتالوگ فقط برای نقش anon و فقط ردیف‌های فعال است.
- پنج دسته‌بندی اولیه ساخته شده‌اند.
- مشتری هنگام ثبت سفارش یکی از دو روش پست یا تیپاکس را انتخاب می‌کند؛ مدیر در پنل می‌تواند روش ارسال، هزینه و کد رهگیری را ثبت یا اصلاح کند. مبلغ کل با هزینه ارسال محاسبه می‌شود و زمان ارسال نیز به‌صورت خودکار در پایگاه داده ثبت می‌شود.
- Edge Function ثبت سفارش و تابع امن `notify-shipping-update` فعال‌اند و Secretهای روبیکا در پروژه جدید ثبت شده‌اند. دریافت پیام آزمایشی تأیید شده است. تابع تغییر وضعیت فقط با نشست مدیر و ایمیل مجاز کار می‌کند.
- هزینه واقعی حمل و صدور بارنامه به‌صورت خودکار از سامانه پست یا تیپاکس هنوز متصل نیست؛ فعلاً مدیر هزینه اعلام‌شده توسط شرکت حمل را دستی ثبت می‌کند. درگاه پرداخت و انتشار عمومی نیز هنوز انجام نشده‌اند.
- تابع ثبت سفارش مستقیماً برای کاربران عمومی قابل اجرا نیست؛ فقط Edge Function سرور مجاز به فراخوانی آن است.
- هشدار باقی‌مانده امنیتی: قابلیت جلوگیری از گذرواژه‌های افشاشده در Supabase Auth هنوز باید در تنظیمات Auth فعال شود.
- هیچ محصول، قیمت یا سفارشی به‌صورت ساختگی ثبت نشده است.

این پروژه در شاخه `computer-mohammadi-store` نگهداری می‌شود و سایت زیورآلات روی شاخه `main` دست‌نخورده باقی می‌ماند.
