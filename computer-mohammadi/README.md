# فروشگاه کامپیوتر محمدی

فروشگاه مستقل لوازم جانبی موبایل و کامپیوتر.

## فایل‌ها
- `index.html`: پیش‌نمایش فروشگاه مشتریان
- `admin.html`: پنل مدیریت محصولات و موجودی

## زیرساخت
- پروژه Supabase مستقل: `computer-mohammadi`
- شناسه پروژه: `fgfeiilkzoajguabzuex`
- جداول اختصاصی: categories, products, customers, orders, order_items, inventory_movements, store_settings
- RLS روی همه جدول‌ها فعال است.
- فقط دسته‌بندی‌ها و محصولات فعال برای بازدیدکننده عمومی قابل خواندن هستند.
- اطلاعات مشتری و سفارش برای عموم بسته است.
- دسترسی مدیریتی به ایمیل مدیر تعیین‌شده محدود شده است.

## راه‌اندازی مدیر
یک‌بار در Supabase Dashboard > Authentication > Users، کاربر مدیر را با ایمیل تعیین‌شده ایجاد و رمز عبور را مستقیماً در همان محیط امن تنظیم کنید. سپس از صفحه `admin.html` وارد شوید. رمز عبور را در کد یا GitHub قرار ندهید.

## وضعیت فعلی
- قالب واکنش‌گرای فارسی فروشگاه آماده است.
- پنل ورود مدیر و مدیریت افزودن/ویرایش/حذف محصول آماده است.
- پنج دسته‌بندی اولیه ساخته شده‌اند.
- اتصال کاتالوگ فروشگاه عمومی به Supabase، ثبت سفارش امن سمت سرور، پرداخت، ارسال پیام و انتشار عمومی هنوز تکمیل نشده‌اند.
- محصولات و قیمت‌های واقعی عمداً وارد نشده‌اند؛ تا زمان دریافت اطلاعات واقعی، موجودی و قیمت ساختگی نمایش داده نمی‌شود.

این پروژه در شاخه `computer-mohammadi-store` نگهداری می‌شود و سایت زیورآلات روی شاخه `main` دست‌نخورده باقی می‌ماند.
