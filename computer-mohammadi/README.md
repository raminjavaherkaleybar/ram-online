# فروشگاه کامپیوتر محمدی

پیش‌نمایش اولیه فروشگاه آنلاین لوازم جانبی موبایل و کامپیوتر.

## وضعیت
- فایل مستقل در مسیر `computer-mohammadi/index.html`
- طراحی فارسی و راست‌چین، واکنش‌گرا برای موبایل و دسکتاپ
- دسته‌بندی و جست‌وجوی نمایشی محصولات
- سبد خرید آزمایشی با ذخیره محلی مرورگر
- بدون اتصال به پایگاه داده یا درگاه پرداخت در این مرحله

## نکته مهم
این پروژه در شاخه `computer-mohammadi-store` نگهداری می‌شود و فایل‌های شاخه `main` و سایت فعلی زیورآلات را تغییر نمی‌دهد. محصولات، قیمت‌ها، موجودی، ثبت سفارش، پنل مدیریت، پیام‌رسان روبیکا و اتصال دیتابیس باید در مراحل بعدی پیاده‌سازی شوند. هیچ‌یک از داده‌های Supabase فروشگاه زیورآلات در این پروژه استفاده نشده است.
