# فروشگاه کامپیوتر محمدی

فروشگاه مستقل لوازم جانبی موبایل و کامپیوتر.

## فایل‌ها
- `index.html`: فروشگاه مشتریان؛ فهرست دسته‌ها و محصولات فعال را از Supabase می‌خواند.
- `admin.html`: پنل ورود مدیر و افزودن، ویرایش و حذف محصولات و مدیریت موجودی.

## زیرساخت
- پروژه Supabase مستقل: `computer-mohammadi`
- شناسه پروژه: `fgfeiilkzoajguabzuex`
- جداول اختصاصی: categories, products, customers, orders, order_items, inventory_movements, store_settings
- RLS روی همه جدول‌ها فعال است.
- فقط دسته‌بندی‌ها و محصولات فعال برای بازدیدکننده عمومی قابل خواندن هستند.
- اطلاعات مشتری و سفارش برای عموم بسته است.
- دسترسی مدیریتی دیتابیس به ایمیل مدیر `raminmkaleybar1363@gmail.com` محدود شده است.
- حساب مدیر در Supabase Auth ساخته شده و ایمیل آن تأیید شده است.

## راه‌اندازی
1. سایت و پنل را از شاخه `computer-mohammadi-store` منتشر کنید.
2. در `admin.html` با ایمیل مدیر و رمز عبوری که فقط خود مدیر تعیین کرده وارد شوید.
3. دسته‌بندی و کالاهای واقعی را با قیمت و موجودی صحیح ثبت کنید.
4. فروشگاه عمومی فقط کالاهای فعال را نشان می‌دهد.

## وضعیت فعلی
- قالب واکنش‌گرای فارسی فروشگاه آماده است.
- اتصال نمایش دسته‌بندی و محصولات فعال به دیتابیس انجام شده است.
- پنل مدیریت محصولات و موجودی آماده است.
- پنج دسته‌بندی اولیه ساخته شده‌اند.
- ثبت سفارش امن سمت سرور، پرداخت، پیام‌رسان و انتشار عمومی هنوز تکمیل نشده‌اند.
- هیچ محصول، قیمت یا سفارشی به‌صورت ساختگی ثبت نشده است.

این پروژه در شاخه `computer-mohammadi-store` نگهداری می‌شود و سایت زیورآلات روی شاخه `main` دست‌نخورده باقی می‌ماند.
